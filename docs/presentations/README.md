# Presentations

저장소 구현과 운영 아키텍처를 설명하는 편집 가능한 발표 자료를 관리한다.

| 자료                                                          | 내용                                                    | 형식                      |
| ------------------------------------------------------------- | ------------------------------------------------------- | ------------------------- |
| [이슈 #44 아키텍처 PPT 키트](issue-44-architecture/README.md) | EIAM 실제 빌드·검증·배포 구조와 범용 WAS·서버 통신 예제 | PPTX, PDF, PNG, 생성 소스 |

발표 자료의 다이어그램과 설명은 실제 구현 소스와 명시적으로 연결한다. 현재
구조가 아닌 참조 예시는 슬라이드 안에서 `선택형 예시` 또는 `목표 구조`로
표시한다.
